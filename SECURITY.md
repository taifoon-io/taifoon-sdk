# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a vulnerability

Do **not** open a public GitHub issue for security vulnerabilities.

Email **taifooon@proton.me** with:
- A description of the vulnerability and its potential impact
- Steps to reproduce or a minimal proof-of-concept
- Your preferred contact for follow-up

We will acknowledge receipt within 48 hours and aim to ship a fix within 14 days for confirmed vulnerabilities. You will be credited in the release notes unless you prefer otherwise.

## Scope

This policy covers `@taifoon/sdk` — the TypeScript client library. For vulnerabilities in the on-chain contracts (`BuildersRegistry`, adapter fleet) or the solver OS itself, use the same contact. For live infrastructure issues (taifoon.io), treat as P0 and email immediately.
